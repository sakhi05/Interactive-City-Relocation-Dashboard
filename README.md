# Interactive City Relocation Dashboard

## 📊 Project Overview
The **Interactive City Relocation Dashboard** is a dynamic Excel-based tool designed to assist individuals and organizations in evaluating and comparing cities for relocation decisions. The dashboard leverages advanced data analysis and visualization techniques to provide actionable insights for business analysts and data analysts.

## ✨ Key Features
- **Multi-Criteria City Comparison:** Analyze cities based on customizable factors such as cost of living, job market, quality of life, climate, and more.
- **Interactive Visualizations:** Utilize slicers, charts, and dynamic tables to filter and explore data in real time.
- **Automated Data Processing:** Macros and formulas streamline data cleaning, aggregation, and reporting.
- **Scenario Analysis:** Model different relocation scenarios and instantly see the impact on key metrics.
- **User-Friendly Interface:** Designed for ease of use by business and data analysts, with clear navigation and documentation.

## 🛠️ Skills Demonstrated
- **Data Analysis:** Data wrangling, transformation, and aggregation using Excel functions and VBA.
- **Dashboard Design:** Building interactive dashboards with advanced Excel features (PivotTables, slicers, conditional formatting).
- **Data Visualization:** Creating clear, insightful charts and visuals to support decision-making.
- **Automation:** Implementing VBA macros to automate repetitive tasks and enhance user experience.
- **Business Acumen:** Translating business requirements into analytical solutions for relocation planning.

## 🚀 How to Use
1. **Open** the `Interactive City Relocation Dashboard.xlsm` file in Microsoft Excel (enable macros for full functionality).
2. **Select** your criteria and preferences using the provided controls (slicers, dropdowns, etc.).
3. **Explore** the interactive charts and tables to compare cities and analyze scenarios.
4. **Export** or present findings as needed for business or personal decision-making.

## 🧰 Technologies Used
- Microsoft Excel (with VBA/macros)
- Data visualization and analysis tools native to Excel
